# 🌐 Web Projects Collection

A collection of beginner–friendly web development projects built using **HTML**, **CSS**, and **JavaScript**.
These projects helped me strengthen my fundamentals and explore real-world functionality such as API usage, DOM manipulation, event handling, animations, and more.

---

## 📁 Projects Included

### 1. ❌⭕ Tic Tac Toe  
A classic 2-player game built with simple game logic and interactive UI.  
**Features**
- Win/draw detection
- Reset game
- Responsive layout

---

### 2. ⛅ Weather App  
A weather dashboard using a public weather API.  
**Features**
- Search for any city
- Displays temperature, humidity, wind speed
- Clean UI with real-time API data

---

### 3. 🎬 Netflix Clone (UI Only)  
A frontend clone of Netflix built using HTML/CSS and JavaScript.  
**Features**
- Horizontal scrolling movie sections
- Hover effects
- Responsive design

---

### 4. ❓ Quiz App  
An interactive quiz application with MCQs.  
**Features**
- Score calculation
- Next/previous question
- Result screen

---

### 5. 🎥 Movie API App  
A movie explorer using a movie database API.  
**Features**
- Search movies
- Show rating, poster, description
- API-based dynamic UI

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Public APIs** (for Weather App & Movie API App)
